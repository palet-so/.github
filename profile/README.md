# Palet

The design canvas built for agents. Ask your agent for a screen, watch it come together on the canvas, and refine it by hand until it's right.

[Website](https://palet.so) · [Try it free](https://app.palet.so/sign-up) · [Docs](https://palet.so/docs) · [Changelog](https://palet.so/changelog)

## Connect your agent

```sh
claude plugin marketplace add palet-so/plugins
claude plugin install palet@palet
```

The plugin connects Claude Code to Palet's hosted MCP server and adds skills for designing from your code and building your designs in it. Codex, Cursor and other MCP clients work too; [palet-so/plugins](https://github.com/palet-so/plugins) has the setup for each. You sign in with your Palet account the first time a tool runs, so there's no API key to manage.
